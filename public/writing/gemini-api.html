Harness the Gemini API in your Dart and Flutter Apps

February 15, 2024 · 5 min read · Gemini, Dart, Flutter, Generative AI
Originally published on The Flutter Blog on Medium ↗.

With the release of the official Google AI Dart SDK (google_generative_ai), bringing Gemini's multimodal capabilities to your Dart and Flutter applications is now straightforward and idiomatic.

Whether you want to generate text responses, summarize user content, analyze photos taken with the device camera, or build dynamic interactive chat streams, the SDK provides a unified interface across all Flutter supported platforms.

Getting Started

First, obtain an API key from Google AI Studio. Add the SDK to your Flutter project: 

flutter pub add google_generative_ai

Initialize the model with your chosen model name (e.g., gemini-1.5-flash or gemini-1.5-pro): 

import 'package:google_generative_ai/google_generative_ai.dart';

final model = GenerativeModel(
  model: 'gemini-1.5-flash',
  apiKey: const String.fromEnvironment('GEMINI_API_KEY'),
);

final prompt = 'Explain how Flutter renders widgets in two sentences.';
final response = await model.generateContent([Content.text(prompt)]);
print(response.text);

Streaming Responses to the UI

For interactive applications, streaming tokens as they generate keeps the UI feeling responsive: 

final responseStream = model.generateContentStream([Content.text(userQuery)]);
await for (final chunk in responseStream) {
  setState(() {
    chatOutput += chunk.text ?? '';
  });
}

Conclusion

With the Dart Gemini SDK, integrating multimodal intelligence into your cross-platform apps is accessible in just a few lines of code. Check out the official repository and samples to build your next AI-enhanced application.
