Hello

I'm a staff engineer at Google focused on agentic applications and generative UI across platforms, and occasionally get to lead my team to build an AI-powered coffee shop. If you've landed here, you probably bumped into me at a conference or saw a video/blog/project that I worked on. Welcome!

Previously, I led developer relations for the Dart and Flutter ecosystems. While working with those technologies, I got to build games, create a YouTube channel, and even talk code with a rock star.

What I'm working on right now

  • Generative UI, an emerging UX paradigm in which agents compose the user interface for an application.
  • A2UI, an open protocol that enables agents and applications to have a conversation about the composition and state of a user interface.
