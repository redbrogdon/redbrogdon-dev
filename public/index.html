I'm a software engineer and Staff Developer Relations Engineer at Google, where I lead teams building developer platforms, agentic application toolchains, and AI developer workflows. For years, I've had the privilege of helping shape the Dart and Flutter developer ecosystems.

Before software engineering, I studied creative writing at university and worked as a poet. Today, I'm fascinated by the craft of software at the boundary between language and execution—how we architect dependable developer abstractions when models begin dynamically generating both code and interface.

Exploring: Generative UI architectures (Flutter GenUI), agent-to-user-interface negotiation via the A2UI protocol, and multiplatform agentic runtimes.

Thinking about: What happens when client application state isn't hand-coded by human engineers, but negotiated in real-time between local agents and dynamic widget catalogs.
