# Dart Blog-to-Video Reference & Guidance

This reference file contains product-specific video production rules, series conventions, and visual standards for official **Dart** video channels.

---

## 1. Video Series Standards

* **Series Examples**: *Technique of the Week*, *Dart Language Deep Dives*, *DartPad Live Coding*, *Wasm & Native Interop*.
* **Talent & Tone**: Precise, clear, logical ("Language Architect's Journal"). Focus on syntax design rationales and language mechanics.
* **Intro / Outro Graphics**: Standard Dart intro title card, animated Dart logo, outro dart.dev documentation callouts.

---

## 2. Visual & Code Cues

* **Syntax & Comparison Animations**: When explaining new Dart language primitives (patterns, records, sealed classes), pair spoken rationale with `#### Graphics` comparison slides contrasting verbose boilerplate against new syntax.
* **DartPad Interactive Calls**: End the outro with a specific callout to try the code interactively on DartPad.
