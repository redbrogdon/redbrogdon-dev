# Flutter Blog-to-Video Reference & Guidance

This reference file contains product-specific video production rules, series conventions, and visual standards for official **Flutter** video channels (e.g. YouTube).

---

## 1. Video Series Standards

* **Series Examples**: *Flutter Widget of the Week*, *Flutter Deep Dives*, *Package Spotlights*, *Impeller / Rendering Mechanics*.
* **Talent & Tone**: Energetic, visual, encouraging ("Builder's Companion"). Pair-programming feel.
* **Intro / Outro Graphics**: Standard Flutter intro title card, animated Flutter logo, outro subscribe & documentation callouts.

---

## 2. Visual & Code Cues

* **UI Side-by-Side**: When demonstrating Flutter widget properties or hot-reload UI changes, pair `#### Script` explanations with `#### Graphics` split-screen cues (Code Editor on left, Mobile/Desktop Emulator preview on right).
* **Widget Shell Step-through**: Introduce Flutter widgets progressively: `StatelessWidget` shell $\rightarrow$ `build` method $\rightarrow$ layout children $\rightarrow$ styling properties.
