# Default Blog-to-Video Reference & Guidance

This reference file contains general video script transformation standards for developer content across Google and open-source tech stacks.

---

## 1. General Video Production Standards

* **Metadata Header**: Standard production metadata table (Author, Title, Series, Product, Talent, YT Description, Thumbnail text).
* **Conversational Dialogue**: Translate written prose into natural, spoken first-person singular dialogue (`I`, `my`, `me`).
* **Visual Offloading**: Move dense data, lists, and code blocks into `#### Graphics` blocks. Spoken `#### Script` dialogue should introduce visual cues rather than reading code line-by-line.
