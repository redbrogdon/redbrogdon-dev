# Default Short Feature Video Reference & Guidance

This reference file contains guidelines for drafting short-form feature highlight or "Tip of the Week" video scripts across developer products.

---

## 1. Format & Structure (~60-90 seconds)

* **Hook (~10-15s)**: Clear developer problem statement or friction point.
* **Body (~60s)**: Feature overview, code demonstration, and key developer benefit.
* **Conclusion (~10s)**: Clear Call to Action (CTA) linking to documentation or repository.
