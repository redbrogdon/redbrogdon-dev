# Dart Technique of the Week (TOTW) Reference & Guidance

This reference file contains guidelines for drafting short-form **Technique of the Week (TOTW)** video scripts for Dart.

---

## 1. Format & Structure (~60-90 seconds)

* **Hook (~10-15s)**: Address a common coding inefficiency or boilerplate pattern in language syntax (e.g. returning multiple values, handling nullability, pattern matching).
* **Body (~60s)**: Introduce the Dart syntax primitive (records, pattern destructuring, sealed classes, guard clauses), show code usage, and explain structural type safety or compiler behavior.
* **Conclusion (~10s)**: CTA directing developers to `dart.dev` or DartPad.

---

## 2. Visual Notes & Graphics Standards

* **3-Column Script Table**:
  * `Script`: Spoken dialogue.
  * `Subtitle or text appearing on slide`: Concise syntax examples tagged with `dart<br>`.
  * `Visual Notes`: Code animations showing variables splitting, type checks merging, or checkmark badges.
