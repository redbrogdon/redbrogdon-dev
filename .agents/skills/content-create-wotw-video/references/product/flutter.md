# Flutter Widget of the Week (WOTW) Reference & Guidance

This reference file contains guidelines for drafting short-form **Widget of the Week (WOTW)** video scripts for Flutter.

---

## 1. Format & Structure (~60-90 seconds)

* **Hook (~10-15s)**: Address a common UI layout challenge or developer pain point solved by a specific Flutter widget.
* **Body (~60s)**: Introduce the widget class, show default constructor usage, and demonstrate 2-3 key property customizations.
* **Conclusion (~10s)**: CTA directing developers to `flutter.dev` or the Flutter YouTube playlist.

---

## 2. Visual Notes & Graphics Standards

* **3-Column Script Table**:
  * `Script`: Spoken words.
  * `Subtitle or text appearing on slide`: Code snippets tagged with `dart<br>` or key subtitle phrases.
  * `Visual Notes`: Split-screen cues showing Code Editor on left, running Flutter emulator widget output on right with animated highlight arrows.
