# Technical Specification: X (Twitter) Copywriting Skill

## 1. Objective & Behavioral Intent
The agent must generate short-form text and multi-post threads for X (formerly Twitter). The output must optimize for high click-through rates (CTR), user dwell time, and platform bookmarks while mitigating programmatic penalties applied by the X feed distribution algorithm.

## 2. Structural & Formatting Standards
The agent must apply the following structural syntax constraints to every generated post:

| Parameter | Operational Rule | Technical Justification |
| :--- | :--- | :--- |
| **Hook Placement** | Locate the core value/hook within the first 60 characters. | Prevents cutoff by mobile layout line breaks. |
| **Density** | Limit text blocks to single-sentence paragraphs. | Enhances readability on mobile screens. |
| **Metatags** | Strict maximum of 2 contextually relevant hashtags. | High density flags automated spam filters. |
| **URL Topology** | Append external links to the terminal end of the content. | Prevents truncation of text segments. |
| **Whitespace** | Enforce a double line break (`\n\n`) between distinct ideas. | Increases scrolling pause rates (Dwell Time). |

## 3. Algorithmic Optimization Profile
When drafting content, the agent must optimize for platform ranking vectors by applying these programmatic guidelines:

* **Asset Priority:** Default to incorporating rich media layouts (clean infographics, functional diagrams, or native video scripts).
* **Link Redirection Protocol:** If external URLs are requested, the agent must isolate them. *Rule:* Direct links in primary posts reduce organic distribution. Instruct the user to place external redirects in the first reply thread.
* **Bookmark Curation Loop:** Structure educational lists, code snippets, tool stacks, or analytical breakdowns as high-utility resource summaries. The algorithm heavily weights the bookmark-to-impression ratio.
* **Thread Continuity:** For complex schemas exceeding 280 characters, generate a sequential thread. Every bridge tweet must end with a visual hook or cliffhanger to maintain reader momentum.

## 4. Copywriting Style Guidelines

* **Voice:** Concise, high-utility, and direct.
* **Grammar:** Strict active voice utilizing high-impact operational verbs (e.g., *Build, Fix, Avoid, Track*). Eliminate adverbs and filler text.
* **Character Budget Allocation:** 
  * *Standard Post:* Max 280 characters.
  * *Premium Post Variant:* Max 4,000 characters, but must execute a truncation break at line 3.

## 5. Execution Framework: High-CTR Thread Hook Templates
When instructed to draft a thread hook, the agent must select and populate exactly one of the following architectural models:

### Model A: The Counter-Intuitive Truth (Shattered Belief)
* **Intent:** Subvert accepted industry standards to drive click-throughs.
* **Template Syntax:**
  ```text
  [Statistic/Metric]% of [Target Audience] fail at [Desirable Goal].

  The worst part? They are following the exact advice experts give them.

  Here is the counter-intuitive framework I used to fix it (and how you can too): 🧵
  ```

### Model B: The Asymmetric Advantage (Gatekept Resource)
* **Intent:** Deliver high-utility curation to drive saves and algorithmic bookmarks.
* **Template Syntax:**
  ```text
  I’ve spent [Timeframe] studying [Complex Topic/Industry Elite].

  Most people spend thousands of hours trying to figure it out on their own.

  Instead, just save yourself the time and read these [Number] simple rules: 🧵
  ```

### Model C: The Reverse Case Study (Zero-to-Hero Friction)
* **Intent:** Leverage personal friction and failure resolution for authentic engagement.
* **Template Syntax:**
  ```text
  I used to think [Common Wrong Assumption]. 

  It cost me [Quantifiable Loss: Time/Money/Opportunity].

  Then I discovered a single [Number]-step loop that changed everything.

  Here is exactly how to replicate it step-by-step: 🧵
  ```

## 6. Output Verification Checklist (Self-Evaluation step)
Before delivering any content generated by this skill, the agent must validate the output against these boolean metrics:
1. Is the absolute first sentence of the post or hook under 60 characters? (Yes/No)
2. Are there any external links located in the first half of the tweet? (Yes/No - *Must be No*)
3. Are all bullet points written as fragments under 10 words? (Yes/No)
4. Are text lines cleanly separated by double line breaks? (Yes/No)


**For Twitter / X (Single Tweet or Thread)**:
- **Tweet 1 (The Hook)**: Spend 50% of creative energy here. Use a specific number, contrarian insight, or open loop. If a thread, append `🧵`.
- **Tweet 2 (Context / The Failure of Defaults)**: Acknowledge the struggle or why standard tools failed to build reader investment.
- **Tweets 3–5 (The Breakthrough & Mechanics)**: Progressive value delivery. 1–2 punchy sentences per tweet (under 150 characters).
- **Final Tweet (Closing & CTA)**: High-level takeaway + single clear CTA/question that invites replies (e.g., *"What routine task are you still doing manually?"*).
