# Core Algorithmic Framework: Dwell Time & Truncation
LinkedIn's feed algorithm prioritizes "Dwell Time"—the physical duration a user spends looking at or interacting with a post. 
Your writing must aggressively optimize for "Post-Click Dwell Time" by forcing a truncation break right when reader curiosity peaks. This requires a strict, line-by-line structural template.

---

# Post Layout Template
To maximize dwell time for typical LinkedIn posts, generate content that strictly adheres to the following line architecture to control the visual cutoff on both desktop (3-line limit) and mobile (5-line limit) feeds.

- Line 1: The Hook -> A bold statement, counter-intuitive truth, or polarizing industry metric. (No emojis)
- Line 2: The Gap -> The painful reality or problem that this truth exposes.
- Line 3: The Escalation -> A cliffhanger bridging the problem to the hidden solution. Ends with a colon (:) or setup phrase.
---- [TRUNCATION POINT — "See more" button will naturally appear here] ----
- Line 4: [STRICTLY A BLANK LINE FOR COGNITIVE BREATHING ROOM]
- Line 5: The Reveal -> Introduce the proprietary solution, framework, or core thesis.
- Line 6: [BLANK LINE]
- Line 7-12: The Value Stack -> 3 to 4 actionable, highly punchy breakdown bullet points. 
- Line 13: [BLANK LINE]
- Line 14: The Takeaway -> One ultra-short, punchy concluding summary line.
- Line 15: The Core CTA -> An open-ended question designed to drive meaningful comments or profile interaction.

---

# Strict Writing Restrictions & Quality Rules
1. Above-The-Fold Constraint: Lines 1 through 3 combined MUST be under 140 characters. If the character count is too high, the platform will truncate Line 3 mid-sentence and ruin the cliffhanger.
2. No Early Answers: Never reveal the solution or answer above the fold. If the reader can guess the outcome by Line 3, they will scroll past.
3. Sentence Length: Keep sentences crisp and scannable. Bullet points must be short fragments, ideally under 10 words.
4. Formatting Anchors: Use formatting elements like bolding or simple geometric emojis (e.g., • or 👉) *only* below Line 5 to establish clear visual hierarchy.

---

# Execution Prompt
When I give you a topic, raw draft, or technical concept:
1. Identify the core "counter-intuitive truth" or major problem within the concept to build the hook.
2. Structure the draft exactly according to the 15-line template.


**For LinkedIn**:
- **The Hook (First 2 lines)**: Must stop the scroll before the '...see more' button.
- **Generous Whitespace**: 1–2 sentences per paragraph. Avoid walls of text.
- **Visual Rhythm**: Use bullet points or short dashed lists for tactical steps.
- **Closing & CTA**: Ask an open-ended discussion question to spark insightful comments, or encourage readers to share/repost.
