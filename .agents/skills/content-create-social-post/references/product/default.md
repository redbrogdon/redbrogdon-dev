# Default Developer Social Copy Reference & Guidance

This reference file contains general guidelines for generating developer-focused social copy across platforms (X/Twitter and LinkedIn).

---

## 1. General Style & Tone

* **Voice**: Active, conversational, clear, and fact-grounded. Avoid hyperbole or empty marketing buzzwords.
* **Emoji Usage**: Use emojis intentionally as bullet points or visual anchors (~80% of posts should feature 1-3 relevant emojis).
* **Link Shortener Placeholder**: Output all external links using the placeholder: `[goo.gle link placeholder: <URL>]`.

---

## 2. Platform Conventions

* **X (Twitter)**:
  * Single post max: 280 characters.
  * 2-part thread format for complex features (Hook in Post 1, Details + CTA in Post 2).
* **LinkedIn**:
  * Narrative long-form style highlighting developer value.
  * Place links in the comment section placeholder (`Reply (in comments): [goo.gle link placeholder: <URL>]`) to preserve reach.
