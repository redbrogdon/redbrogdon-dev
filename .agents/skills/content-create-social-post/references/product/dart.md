# Dart Social Copy Reference & Guidance

This reference file contains product-specific guidelines and channel DNA for generating social media copy for official **Dart** channels.

---

## 1. Channel DNA & Brand Voice

* **Handle / Tagging**: `@Dart_Lang` on X, `Dart` on LinkedIn.
* **Tone**: Precise, logical, language-focused, and benchmarking-driven.
* **Key Hashtags & Tags**: `#Dart`, `#DartLang`, `#ProgrammingLanguages`.
* **Emoji Conventions**:
  * Primary Dart Emoji: 🎯 (Target)
  * Feature/Syntax Emojis: ⚡ (Performance/Wasm), 🧩 (Pattern matching/Macros), 🔒 (Soundness/Null safety), 📦 (pub.dev packages)

---

## 2. Category Blueprints

### A. Releases & Language Version Updates
* **Hook**: 📣 *Announcing Dart X.Y!* 🎯
* **Content**: Highlight syntax primitives, type system updates, compiler performance, or WebAssembly compilation.
* **CTA**: Link to changelog or DartPad sample via `[goo.gle link placeholder: <URL>]`.

### B. Language Feature Spotlight
* **Hook**: 🧩 *Looking for a cleaner way to return multiple values or destructure types?*
* **Content**: Show concise syntax before/after example or DartPad demo.
* **CTA**: Try live on DartPad via `[goo.gle link placeholder: <URL>]`.
