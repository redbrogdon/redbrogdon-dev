# Default Video-to-Blog Reference & Guidance

This reference file contains general rules for converting video scripts, transcripts, and graphic cues into structured technical blog posts across developer products.

---

## 1. General Conversion Rules

* **Written Polish**: Eliminate video filler (e.g. "like and subscribe", "comment below", "as you can see on screen").
* **Code Consolidation**: Consolidate live-coding step fragments into clean, copy-pasteable blocks representing the final state.
* **Active URL Resolution**: Replace spoken references to tools or codelabs with active Markdown hyperlinks.
