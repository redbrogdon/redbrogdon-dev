# Dart Video-to-Blog Reference & Guidance

This reference file contains product-specific rules for converting video scripts and transcripts into written articles for the **Dart** blog ecosystem.

---

## 1. Publishing & Platform Guidance

* **Target CMS**: Medium-hosted Dart Blog or dart.dev documentation.
* **Frontmatter Keys**: Standard `title`, `date`, `author`, `tags` (`dart`, `syntax`, `performance`, `wasm`).
* **Code Consolidation**: Consolidate live-coding video snippets into clean, copy-pasteable Dart code blocks with inline comments, and include interactive DartPad links where appropriate.
