# Flutter Video-to-Blog Reference & Guidance

This reference file contains product-specific rules for converting video scripts and transcripts into written articles for the **Flutter** blog ecosystem.

---

## 1. Publishing & Platform Guidance

* **Target CMS**: Medium-hosted Flutter Blog or self-hosted documentation.
* **Frontmatter Keys**: Standard `title`, `date`, `author`, `tags` (`flutter`, `mobile`, `web`, `desktop`).
* **Visual Reconstruction**: Reconstruct UI video demos into descriptive paragraph text paired with visual placeholders (`*Image: [UI screenshot description]*`).
