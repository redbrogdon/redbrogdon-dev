# Flutter Blog Post Reference & Guidance

This reference file contains product-specific guidelines, tone DNA, and specialized blueprints for articles intended for the official **Flutter Blog** (`blog.flutter.dev`).

---

## 1. Product Tone Persona ("Builder's Companion")

* **Tone DNA**: Warm, conversational, visual-heavy, and encouraging. Focus on creative freedom and multiplatform productivity ("what developers can build across mobile, web, and desktop").
* **Style**: Active, engaging, pair-programming feel. Focus on practical UI craftsmanship without corporate jargon.

---

## 2. Product-Specific Community Metrics

* For release posts and ecosystem highlights, include Flutter-specific community metrics where available (e.g. unique contributor count, commits, package downloads on `pub.dev`, community showcases).

---

## 3. Progressive UI Disclosure & Visual Rules

* **Progressive UI Disclosure**: Break down complex UI widgets or state flows into progressive steps (shell widget $\rightarrow$ properties $\rightarrow$ state management integration).
* **Visual Placeholders**: Use descriptive visual placeholders for UI screenshots and demo videos:
  * `*Image: [Detailed description of what the UI image shows - Caption: [Short caption]]*`
  * `*Video: [Demo video description or link]*`

---

## 4. Specialized Flutter Blueprints

### A. SDK Release Additions
*(Extends Universal Blueprint 1)*
* Include dedicated subsections for Rendering/Engine updates (**Impeller**), core Framework APIs, platform-specific updates (**iOS, Android, Web, Desktop**), and DevTools extensions.

### B. AI & Agentic Development (GenUi)
1. **Visionary Hook**: Paradigm shift in multiplatform UI or development workflows using AI.
2. **Project Introduction**: Walkthrough of a concrete AI-powered app or UI library.
3. **Architecture & Data Flow**: Monorepo setup, backend integrations (Firebase/Cloud Functions), and model choices.
4. **Prompt & API Walkthrough**: Prompt templates and Dart SDK integration blocks.
5. **Security & Moderation**: Safety filters and security rules.
